# 기능 구현

1. 사용자 입력 기능

- 구분자와 양수인 숫자가 포함된 문자열을 입력 받는다.
- @woowacourse/mission-utils의 Console API를 사용하여 입력 받는다.

2. 입력 처리 기능

- 구분자(기본, 커스텀) 없이 숫자만 입력도 가능하다.
- 기본 구분자는 쉼표(,) 또는 콜론(:) 이며, 이를 기준으로 분리한다.
- 커스텀 구분자도 입력할 수 있는데 반드시 "//"와 "\n" 사이에 있어야 하며, 숫자 문자열 앞에 있어야 한다.
  즉, 커스텀 구분자를 사용하면은 바로 뒤에 있는 문자열을 커스텀 대상 문자열로 인식한다.

3. 숫자 계산 출력 기능

- 빈 문자열인 경우 0으로 출력한다.
- 구분자로 분리된 숫자들을 합하여 출력한다.
- @woowacourse/mission-utils의 Console API를 사용하여 출력한다.

# 사용자 입력 에러 처리

- 숫자 문자열이 음수이면은 에러를 던진다.
- 숫자 문자열이 (Number.MAX_SAFE_INTEGER) 9007199254740991를 넘는경우
- 양수인 숫자 혹은 구분자 둘 중에 하나를 빠뜨리면 에러를 던진다.
- 커스텀 구분자를 사용할때, 커스텀 구분자가 아닌 다른 구분자로 숫자들을 구분을 할 경우 에러를 던진다.
  (ex //;\n1:2:3)

| 예외상황                                                | 예시                                     |
| ------------------------------------------------------- | ---------------------------------------- |
| 구분자를 제대로 사용하지 않은 경우                      | 1@2@3                                    |
| 구분자가 가장 먼저 나오지 않는 경우                     | 123123//;\n1;2;3                         |
| 숫자 문자열이 안전한 정수(9007199254740991)를 넘는 경우 | 9007199254740992, 9007199254740990: 1: 2 |
| 숫자 문자열이 음수인 경우                               | -1,2,3                                   |
| 숫자 문자열를 제대로 사용하지 않은 경우                 | 1:2:A                                    |
| 커스텀 구분자 사용시 다른 구분자로 문자열을 나눌떄      | //;\n1:2:3, //1:2:3//;\n1;2;3            |
